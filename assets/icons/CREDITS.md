# Icon credits

The game's icons come from **Free Icon Pack v3.1 (Basic)** by gvesster
(<https://linktr.ee/gvesster>, @gvesster on X).

The pack's licence allows its icons in commercial projects. It does not allow
redistributing or reselling the icons as an asset pack, so this folder holds
only the icons the game uses, downscaled to 128 px. The full pack is not
committed to this repository and should not be added to it.
